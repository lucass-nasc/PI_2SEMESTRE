# Sistema de Atendimento de Pronto Socorro — Projeto Integrador II

O Sistema de Atendimento de Pronto Socorro é um projeto desenvolvido para a disciplina de Projeto Integrador II, com o objetivo de otimizar o fluxo de atendimento em unidades de pronto socorro. A proposta contempla o cadastro de pacientes, a triagem por nível de gravidade e o acompanhamento do atendimento até a alta, buscando reduzir o tempo de espera e garantir que os casos mais urgentes sejam priorizados corretamente.
